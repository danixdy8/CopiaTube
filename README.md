MiTube - Plataforma Multimedia (Proyecto Académico)
Este repositorio contiene el diseño y la estructura de una plataforma de streaming de video desarrollada exclusivamente con HTML5 y CSS3. El objetivo principal fue replicar la lógica de navegación y el layout de plataformas como YouTube utilizando únicamente tecnologías nativas de la web, cumpliendo con estándares de semántica y diseño responsivo.

🚀 Características Técnicas
Arquitectura de Navegación: Sistema de navegación cíclica entre archivos HTML independientes mediante anclajes y rutas relativas.

Layout Profesional: Uso de CSS Flexbox para gestionar un diseño de doble columna (reproductor y sidebar de sugerencias).

Diseño Responsivo: Adaptación completa a dispositivos móviles mediante Media Queries.

Estética Cyberpunk: Interfaz oscura con acentos en cian, tipografía moderna ('DM Sans') y efectos de iluminación (glow) mediante drop-shadow.

HTML5 Semántico: Organización estricta mediante etiquetas header, nav, main, section, article, aside y footer.

⚠️ Nota sobre los archivos multimedia
Para mantener este repositorio ligero y optimizado según las buenas prácticas de GitHub:

Videos (.mp4): No se incluyen los archivos de video pesados en este repositorio.

Posters (.webp): Las imágenes de previsualización se omiten para centrar el portafolio en el código fuente.

Instrucciones para visualizar el código:
El código está configurado para buscar recursos en la carpeta local /embed_Multimedia/. Para ver el proyecto en funcionamiento, basta con colocar archivos de video propios en dicha ruta siguiendo los nombres definidos en los archivos .html.

🛠️ Tecnologías
HTML5: Implementación de etiquetas de video nativas.

CSS3: Variables CSS (Custom Properties), Flexbox, y animaciones de transición.

Google Fonts: Integración de fuentes externas.
