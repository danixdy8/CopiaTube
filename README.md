# MiTube - Plataforma Multimedia (Proyecto UIDE)

Este proyecto es una simulación de una plataforma de contenido multimedia desarrollada exclusivamente con **HTML5 y CSS3**, sin el uso de JavaScript.

## 📋 Características
- Navegación cíclica entre 5 videos independientes.
- Diseño "Responsive" con Flexbox (dos columnas para escritorio, una para móviles).
- Uso de etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- Interfaz con acento **Cian/Cyberpunk**.

## ⚠️ Nota sobre los archivos multimedia
Debido a las restricciones de tamaño de GitHub (Límite de 100MB por archivo), los videos originales en formato `.mp4` y los posters `.webp` **no se han subido a este repositorio** para evitar errores de sincronización.

**Para probar el funcionamiento completo:**
1. Descargue el archivo `.zip` adjunto en la entrega de la tarea (Canvas/Moodle).
2. Asegúrese de que la carpeta `embed_Multimedia` esté en la misma raíz que los archivos HTML.
3. Los videos y posters están organizados en:
   - `embed_Multimedia/` (Videos .mp4)
   - `embed_Multimedia/images/` (Posters .webp)

## 🛠️ Tecnologías utilizadas
- **HTML5**: Estructura y reproducción nativa de video.
- **CSS3**: Diseño de tarjetas, efectos de iluminación (glow) y layout.
- **Google Fonts**: Tipografía 'DM Sans'.
